Why the TER didn't catch the issues we're now seeing on the fleet

A read of the latest Test Exit Report against the live known-issues list. Short version: the trains were never validated the way the question assumes — the TER is a software functional test on a 4-car bench, and it says so itself.

Source: ND-DEVOPS-OBB-TER-026-04 (v4, 16 Apr 2026) Build: Nomad Connect 2025.2.1 Bench: Newcastle T112

In one line

The TER proves the 2025.2.1 software build is functionally sound on a representative bench. It was never a per-train, per-platform, at-scale commissioning sign-off — and it explicitly disclaims the exact conditions where our issues live.

Every problem we're hitting now sits in the 6-car / multi-device-batch / non-nv4 / physical-cabling space that a clean 4-car nv4 bench structurally could not reach.

01What the TER actually is

It is a functional test of a software release, run on one bench — not a commissioning report for 50+ trains.

The document validates Nomad Connect 2025.2.1 against the Newcastle bench (T112) to clear it for fleetwide release. That is a real and useful thing — but its shape matters. The bench is a fixed, clean, 4-car nv4 setup, and the report caveats its own reach in plain language.

03So why now, and not earlier?

Because in-country commissioning is the first point at which these conditions exist together: real 6-car consists, real per-train cabling, multi-device batch operations, and the non-nv4 platforms. None of that was — or could be — present on a single clean 4-car nv4 bench. The TER did its job for what it covers; it was simply never positioned to cover this.

That's also consistent with the report's own recommendation: functional bench testing first, then in-country testing to be completed at a later date. We are in that later phase, and it is doing exactly what it's meant to — surfacing the fleet-scale and platform-specific issues the bench can't.

Bottom line for the thread

The TER validated the software build, not the fleet rollout. It covered a 4-car nv4 bench with single-device OBN operations, and disclaimed 6-car, batch, non-nv4, and physical cabling in its own text.

The issues we're finding are precisely in those un-reachable areas — which is why in-country commissioning is where they were always going to appear first, and where they're appearing now.
