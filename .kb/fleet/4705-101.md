# The validated fv5 `obn report` recipe (2026-07-02)

All **four** are required — missing any one breaks it:

1. **nd-obn 2.3.6** — has the fv5/fv6 hardcoded branches in `DostoNeuReport` (RD-11895, in every
   tag ≥2.2.24). The fleet pin **2.2.23 has no fv5/fv6** → fv5 matches no branch → empty/OOM.
2. **Bug-10 BFS guard** — hand-patch; **no released version has it**. Without it an unnumbered
   device re-enqueues forever → 100% CPU + unbounded RSS. The shipped
   `fix_obn_bug10_report_dosto_neu_bfs.py` anchor FAILS on 2.3.6 (old nv6-END form) — use a narrower
   anchor (`if to_device.coach_number is not None:` before the `queue.appendleft`).
3. **`backbone-discovery.yaml`: `train_type: fv5` + `report_module: DostoNeuReport`** — package
   DEFAULTS are `train_type: mq` + `report_module: GenericReport`, which routes to the topology
   engine → "No topology configured for train type mq".
4. **Template Fzg hardcode** — installed `nd-obn-template-dostoneu-fv5` 0.0.16 has the broken line-1
   `128 + train_id` (box 42 → 170, not 229). Temp fix: line 1 of all 15 `fv5-*.cfg` →
   `{%- set train_id = 229 -%}`.

**Result:** report ran ~5s (bounded mem), `obn validate` gave the full 5-coach fv5 table.

# Known quirks / dead ends

- **All four ingredients are NON-DURABLE** — wiped by factory up / snapshot promote / template-pkg
  update. On these CCUs `/usr` + `/etc` are RO btrfs subvols. **This is a test article, not a
  durable state.** The durable fix is box=Fzg re-IP + v9 templates + nd-obn with fv5/fv6+bug10 native
  (TRIAG-8585 → 2.3.14) + Puppet enforcing train_type/report_module.
- **rules.yaml config key is deliberately numberless** (`config: fv5-A1-v8`) — that is validate's
  "expected"/version-compare key. The `template:` renders the real Fzg hostname. The Fzg-hardcode
  fixes the *template render*, NOT the v3→v8 `✗` (that needs a real `obn update c` config push).
- **`backbone-discovery.yaml` identity fields are garbage on t42** (`project_id:10, train_id:101`,
  should be 51/42). Live works because facter `nd.yaml` + interfaces are the operative source — but
  any OBN path reading identity from that file would compute wrong subnets. Reconcile at re-IP.
