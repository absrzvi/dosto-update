# Known quirks

- **`obn report` OOM-loop = Bug 10 (BFS guard) wiped.** On 2026-06-24 this commissioned train was
  throwing 30+ **frozen** Zabbix alarms dated **June 12** (switches "unavailable by ICMP" + a wall
  of `7.7.7.7` AP sentinels). Root cause: `obn report` allocated ~60GB RSS and was OOM-killed 4× in
  24h; `nd-backbone-discovery.service` stuck `activating` ~24 min per cycle. Patch check read **9/11**
  — Bug 10 (`NDP-PATCH-BUG10-BFS-GUARD`) and Bug 11 were **missing**, despite OBN being 2.2.23 (which
  is supposed to ship bugs 1-10 native) — a recent snapshot promote / nd-obn rewrite had wiped
  `/usr/share/obn` back to a pre-marker state on run1.
- **Why the alarms were frozen (not self-healing).** The OBN→NMS→Zabbix **publish** half needs
  `obn report` to succeed; it OOM-died every cycle → nothing propagated → stale June-12 IPs and
  `7.7.7.7` sentinels never cleared. A crashed report stage produces frozen, non-self-clearing
  alarms — unlike an offline-train ICMP flood, which self-heals on power-up.
- **Topology count 43 ≠ 42 expected.** `obn discover` sees 43 devices vs 18 SW + 24 AP = 42.
  The Bug-10 patch stops the crash but does not conjure/remove the stray node — needs an
  `obn validate` / device-discovery follow-up to find the real device gap.

# Proven dead ends

- Do **not** assume "OBN is 2.2.23, therefore Bug 10 is native/present." A promote can wipe the
  marker form back to unpatched. **Verify live** with `dosto-obn-patches --check` before trusting it.
- Reconcile alone would only half-fix (switch IPs) — the `7.7.7.7` AP sentinels need a *successful
  publish*, which needs the Bug-10 patch in place first.

# Fix applied 2026-06-24 (live, engineer-authorized)

1. Killed the runaway `obn report`; **stopped `nd-backbone-discovery.timer`** to halt the loop.
2. Applied Bug 10 + Bug 11 under btrfs ro-toggle → verified **11/11** markers; memory flat ~5.5GB.
3. Persisted via NDSU chroot → run2 (id 349); rebooted, verified 11/11 survived; `obn report` now
   exits 0 at ~16 MB. **Re-enabled the discovery timer.**
