## Part B — Storm-control rate limits (109 + 110) — **Gate 1 approval**

Targets per train: `e0-2` on **A1, A3, B1, B3** (Frontkupplung) + `e1-4` on **A3** (Stadler FW trunk). Value: `broadcast 1 M` (leaky-bucket; caps ARP/DHCP storm component; manual §8.7).
Known limitations (accepted): does NOT cap multicast (IGMP/mDNS legs of a loop) or flooded unicast; incompatible with `inbound` limiter on the same port (we use none).

Run **on each CCU** (resolves fresh IPs, one CLI command per session):

```bash
# resolve cab switches
sudo dhcp-lease-list 2>/dev/null | grep -E "nv6-(A1|A3|B1|B3)-" 
# for each cab switch IP $SW:
swcmd $SW "configure interface e0-2 switchport rate-limit broadcast 1 M"
# additionally on A3 only:
swcmd $A3 "configure interface e1-4 switchport rate-limit broadcast 1 M"
# persist (each switch, admin):
swcmd $SW "save running-config force"
```

Or as a loop (paste on the CCU after defining `swcmd`):

```bash
LEASES=$(sudo dhcp-lease-list 2>/dev/null)
for role in A1 A3 B1 B3; do
  SW=$(echo "$LEASES" | grep "nv6-${role}-" | awk '{print $2}')
  echo "== $role @ $SW =="
  swcmd $SW "configure interface e0-2 switchport rate-limit broadcast 1 M"
  [ "$role" = "A3" ] && swcmd $SW "configure interface e1-4 switchport rate-limit broadcast 1 M"
  swcmd $SW "save running-config force"
done
```

Verify per switch: `swcmd $SW "show running-config"` → e0-2 (and A3 e1-4) stanza contains `switchport rate-limit broadcast 1 M`. Spot-check QoS view: `show qos interfaces`.
